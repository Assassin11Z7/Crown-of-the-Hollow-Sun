# Prose contract

Each chapter is a markdown file:

```
# Chapter N
## Title Here

First paragraph.

Second paragraph.
```

- One `# Chapter N` and one `## Title`.
- Blank line between paragraphs.
- Italics with *single asterisks* only. No bold. No lists.
- Scene break: a line with only `*` at most once per chapter.
- Each chapter: 1,500–2,200 words. 12–20 paragraphs.
- Open in motion. One POV. End on a turn.
- No meta commentary in the file.
